Constructor:

It is a special member function of a class:

1. It has the same name as the class.
2. It is called automatically when an object is created.
3. It is used to initialize data members.
4. It has no return type.

## Types of Constructors

1. Default Constructor

a. No parameters.
b. Sets class members with default values of their data types.
c. If we do not define any constructor, a default constructor is generated by compiler.
d. In classes, default access is private.

2. Parameterized Constructor

a. Constructor that accepts parameters (used to pass values during object creation).
b. For parameterized constructor, we can use initializer list. It is faster, better,
   and a recommended way to initialize class data members.

3. Constructor Overloading

a. Multiple constructors in the same class.

4. Copy Constructor

a. Used when an object is created from another object.

Syntax: `ClassName(const ClassName& obj)`
